# SkyCast Weather App

A responsive weather dashboard built with original HTML, CSS and vanilla JavaScript.

## Features
- Search weather by city
- Current temperature, feels-like temperature, humidity and wind speed
- Seven-day high/low forecast
- Sunrise, sunset, daylight duration and UV index
- Celsius/Fahrenheit toggle
- Responsive layout for desktop and mobile
- Weather and geocoding data from Open-Meteo; no API key required for this demo

## Run locally
1. Download and extract the project.
2. Open the `skycast-weather-app` folder in VS Code.
3. Open `index.html` in your browser. If your browser blocks network requests from local files, use the VS Code Live Server extension and choose **Open with Live Server**.

An internet connection is required to load fonts and live weather data.

## Publish on GitHub
1. Create a new repository on your GitHub profile, for example `skycast-weather-app`.
2. Upload `index.html`, the `css` folder, the `js` folder, and this README.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/ (root)`, then save.
5. Wait a minute or two and open the published URL shown in GitHub Pages.

## Data source
Weather forecast and geocoding are provided by [Open-Meteo](https://open-meteo.com/). See its website for current API terms and attribution guidance before public or commercial deployment.

## Customization
Change the brand name, text and colors in `index.html` and `css/style.css` to suit your portfolio.
